# Regras permanentes, por exemplo:

- nunca alterar a identidade visual;
- sempre manter responsividade;
- reutilizar componentes;
- não instalar dependências sem necessidade;
- não criar CSS inline;
- manter acessibilidade;
- não remover funcionalidades existentes.

# Recursos de imagem

- Sempre verificar a pasta public antes de utilizar imagens externas.
- Priorizar imagens reais do escritório.
- Não substituir fotografias oficiais por imagens de banco sem autorização.
- Quando uma nova funcionalidade exigir uma imagem inexistente, informar claramente qual imagem é necessária.
