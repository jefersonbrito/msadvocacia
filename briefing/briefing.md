# Projeto - MS Advocacia e Consultoria

## Objetivo
Criar um site institucional moderno para um escritório de advocacia.

O site deve transmitir:
- autoridade
- sofisticação
- confiança
- advocacia moderna

## Público alvo
- empresas
- empresários
- clientes corporativos
- clientes premium

## Referências
- https://camilasoares.adv.br/
- https://vlvadvogados.com/

## Estrutura do site

### Home
- banner principal
- frase de impacto
- botão WhatsApp

### Sobre
- história do escritório
- missão
- valores

### Áreas de atuação
- Direito Empresarial
- Direito Tributário
- Direito Trabalhista
- Compliance
- Contratos

### Parceiros
Sessão para parceiros jurídicos.

### Contato
- formulário
- WhatsApp
- Google Maps

## Requisitos técnicos
- Vue 3
- Vite
- TailwindCSS
- Responsivo
- SEO
- Performance
- Design premium

## Observações
O visual não deve parecer template genérico.
Priorizar aparência sofisticada e moderna.
